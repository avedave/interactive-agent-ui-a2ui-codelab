8. Congratulations & Clean Up

What You Built and Learned

Congratulations! You built and deployed a complete agent-driven interface using A2UI, Gemini 3.8 Flash, and Google Cloud Run.

Here is what you accomplished:

  • Architectural Security: Solved the trust-boundary challenge by using declarative JSON instead of risky HTML/code execution.
  • Progressive Disclosure: Built a baseline text agent first and upgraded it seamlessly to rich generative UI.
  • Zero-Build Web Components: Embedded the <a2ui-surface> renderer using browser ES modules without requiring npm build pipelines.
  • Prompt-First Catalog Design: Taught Gemini how to dynamically route between text advice and visual UI components.
  • Two-Way Interactivity: Connected client button events to server-side mutations with real-time UI updates on Cloud Run.

Clean Up Resources

To avoid incurring ongoing charges to your Google Cloud account for the deployed Cloud Run services, delete them when you are finished:

gcloud run services delete smart-home-baseline --region "${GOOGLE_CLOUD_REGION}" --quiet
gcloud run services delete smart-home-a2ui --region "${GOOGLE_CLOUD_REGION}" --quiet

Important: Deleting unused Cloud Run services prevents unexpected monthly charges on your Google Cloud billing account.
