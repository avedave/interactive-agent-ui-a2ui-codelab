2. Environment & Vertex AI Setup

In this step, you will prepare your Google Cloud environment, enable the necessary Cloud APIs, and configure Vertex AI access.

Launch Google Cloud Shell

Open the Google Cloud Console in your browser, log in to your Google Cloud account, and click the Activate Cloud Shell button in the top right corner.

Cloud Shell provides a pre-configured Linux terminal with gcloud, python3, and git already installed.

Set your Project ID and Region

In Cloud Shell, set your Google Cloud project and preferred region as shell environment variables:

# Set your active Google Cloud Project ID
export GOOGLE_CLOUD_PROJECT="$(gcloud config get-value project)"
export GOOGLE_CLOUD_REGION="us-central1"

echo "Project ID: ${GOOGLE_CLOUD_PROJECT}"
echo "Region:     ${GOOGLE_CLOUD_REGION}"

Enable Required Google Cloud APIs

Enable the APIs for Cloud Run, Vertex AI, and Cloud Build:

gcloud services enable \
  run.googleapis.com \
  aiplatform.googleapis.com \
  cloudbuild.googleapis.com

Configure IAM Permissions for Vertex AI

When running in Google Cloud, your application authenticates via Application Default Credentials (ADC).

For Cloud Run, the service executes using the default Compute Engine service account. You must grant this service account the Vertex AI User role so it can query Gemini models on Vertex AI:

# Retrieve the default compute service account number
export PROJECT_NUMBER="$(gcloud projects describe ${GOOGLE_CLOUD_PROJECT} --format='value(projectNumber)')"
export CLOUD_RUN_SA="${PROJECT_NUMBER}-compute@developer.gserviceaccount.com"

# Grant the Vertex AI User role
gcloud projects add-iam-policy-binding "${GOOGLE_CLOUD_PROJECT}" \
  --member="serviceAccount:${CLOUD_RUN_SA}" \
  --role="roles/aiplatform.user"

Tip: If you are testing locally or from a machine outside Cloud Shell, run gcloud auth application-default login to authenticate your user account with Vertex AI.

Create the Workspace Directory

Create a dedicated directory for the codelab and set up a Python virtual environment:

mkdir -p ~/a2ui-codelab/01-baseline && cd ~/a2ui-codelab/01-baseline
python3 -m venv .venv
source .venv/bin/activate

Install Dependencies

Create a requirements.txt file pinned to recent stable versions:

cat << 'EOF' > requirements.txt
fastapi==0.141.1
uvicorn[standard]==0.54.0
google-genai==2.25.0
EOF

pip install -r requirements.txt
