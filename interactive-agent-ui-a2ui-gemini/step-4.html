4. Deploying the Baseline to Cloud Run

Deploying early ensures your container builds cleanly and validates your Cloud Run environment and Vertex AI permissions before making deeper code additions.

Create the Dockerfile

Create a production Dockerfile in ~/a2ui-codelab/01-baseline:

cat << 'EOF' > Dockerfile
FROM python:3.11-slim

WORKDIR /app

ENV PYTHONUNBUFFERED=1
ENV PORT=8080

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8080

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8080"]
EOF

Deploy to Cloud Run

Run gcloud run deploy directly from the source directory. Cloud Build will automatically build the container image and deploy it:

gcloud run deploy smart-home-baseline \
  --source . \
  --region "${GOOGLE_CLOUD_REGION}" \
  --allow-unauthenticated \
  --set-env-vars GOOGLE_CLOUD_PROJECT="${GOOGLE_CLOUD_PROJECT}",GOOGLE_CLOUD_REGION="${GOOGLE_CLOUD_REGION}"

When deployment finishes, gcloud outputs a live service URL:

Service URL: https://smart-home-baseline-xxxxxx-uc.a.run.app

Open the service URL in your browser. Verify that your baseline agent is live in the cloud and communicates successfully with Gemini on Vertex AI.
