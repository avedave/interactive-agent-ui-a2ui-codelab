7. Adding Two-Way Interactivity & Redeploying

In this step, you will test two-way interaction locally and redeploy the upgraded application to Cloud Run.

Test Locally

From ~/a2ui-codelab/02-a2ui, launch the server:

uvicorn main:app --host 0.0.0.0 --port 8080

Open the Web Preview on port 8080 in Cloud Shell.

  • Test Text Advice:
    • Ask: "What is a healthy indoor humidity?"
    • Verify: Gemini responds purely in text. No UI surface is rendered.
  • Test A2UI Surface Rendering:
    • Click the prompt chip: "🏠 Show home dashboard"
    • Verify: Gemini returns a text introduction AND immediately renders the interactive A2UI dashboard cards!
  • Test Two-Way Interaction:
    • Click the "Turn OFF" button next to Living Room Ceiling.
    • Watch the button immediately toggle to "Turn ON", the status text update to "OFF (0%)", and a toast notification appear confirming the update!
    • Click "Warmer (73°F)" on the Thermostat card. Notice the target temperature increment and the buttons adapt to the new state.

Success: You have verified that user interactions on client widgets seamlessly round-trip to the Python backend, update in-memory state, and refresh the UI without a full page reload!

Stop the server with Ctrl+C.

Redeploy Upgraded Application to Cloud Run

Deploy your A2UI application directly to Cloud Run:

gcloud run deploy smart-home-a2ui \
  --source . \
  --region "${GOOGLE_CLOUD_REGION}" \
  --allow-unauthenticated \
  --set-env-vars GOOGLE_CLOUD_PROJECT="${GOOGLE_CLOUD_PROJECT}",GOOGLE_CLOUD_REGION="${GOOGLE_CLOUD_REGION}"

Once the deployment completes, open the provided Service URL. You now have a complete, secure, agent-driven user interface running in Google Cloud!
